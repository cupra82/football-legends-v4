# Football Legends 4.0.6 — Fix usabilità (PC)

- Home compatta: pulsanti **CREA UNA SFIDA** e **GIOCA UN TORNEO** subito visibili.
- Punteggio attuale dei giocatori sempre visibile durante il quiz, anche con domande lunghe.
- Risposte più compatte: meno scorrimento per vedere tutte e tre le opzioni.
- Eliminazione degli almanacchi tautologici: mostra una nota solo quando aggiunge un fatto storico, non quando ripete la risposta. Il link **Consulta la fonte** resta assente dall'interfaccia.
- MATCH DAY centrato, senza regressioni al fix 4.0.5.
- Nessuna modifica a regole, punti, Elo, salvataggi, Supabase e archivi delle domande.

## Installazione consigliata
Apri GitHub Desktop e seleziona `football-legends-v4`. Estrai lo ZIP rapido e copia i sei file (index.html, v400.css, v400-design.js, v403-ui.js, v404-wow.js, server.js) nella radice del repository sostituendo gli omonimi. Esegui Commit to main e Push origin. Aspetta il Live di Render e ricarica con Ctrl+Shift+R. Non eseguire workflow di generazione delle domande.
