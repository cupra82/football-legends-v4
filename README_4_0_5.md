# Football Legends 4.0.5 — Match Day centrato + 3 risposte visibili

## Correzioni
1. La schermata MATCH DAY rimane al centro anche durante le animazioni complete.
2. A ogni domanda, la pagina viene riportata automaticamente sulla scheda quiz (non all’inizio della pagina).
3. Domanda, intervalli e tre opzioni sono più compatti, anche su schermi laptop.
4. Quando termina la presentazione VS, il quiz viene riposizionato correttamente.

La logica delle partite, i dati Supabase, le domande e la classifica sono invariati.

## Installazione più facile
Dal pacchetto sostituisci `index.html`, `v404-wow.css`, `v404-wow.js`, `server.js`, `package.json` nel repository `football-legends-v4`.
Oppure copia tutto il pacchetto, **senza cancellare i grandi JSON `*-generated.json` già nel repository**.
Commit to main, Push origin; attendi Render Live; Ctrl+Shift+R.
Non serve eseguire GitHub Actions.
